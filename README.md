# Aditi Priya — Portfolio

A Netflix-style cinematic personal portfolio built with React, TypeScript, Vite, Tailwind CSS v4, and Framer Motion.

## 🚀 Run locally

```bash
npm install
npm run dev
```

Then open **http://localhost:5173**

## 🛠 Stack

- **React 18** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Framer Motion** (animations)
- **Lenis** (smooth scroll)

## 📁 Structure

```
src/
  data/portfolio.ts   ← All portfolio content lives here
  components/         ← UI components
  hooks/              ← Custom hooks
public/
  assets/             ← Images, resume PDF
```

## ✏️ Customising

All content (name, projects, skills, experience, achievements) is in a **single file**:
[`src/data/portfolio.ts`](./src/data/portfolio.ts)

This project is **completely standalone** — not connected to any GitHub repository.
